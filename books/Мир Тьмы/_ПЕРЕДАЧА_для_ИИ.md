## 1. Задача и пожелания пользователя

Пользователь делает свою систему **по VtM V20, с контентом из старых редакций** (Revised, 2nd, 1st, Dark Ages), а также оборотней W20, магов M20, призраков (Wraith 20) и подменышей (C20). Для неё собирается **подробный русский справочник механики** по его PDF-книгам Мира Тьмы. Пять линеек:
- **Вампиры** (VtM: V20, V20 Dark Ages, Revised/2nd, разное) — **готово**;
- **Оборотни** — только W20 (20-я редакция) — **готово**;
- **Маги** — M20 и Викторианская эпоха (Victorian Age) — **готово**;
- **Призраки** — Wraith: The Oblivion 20th (3 книги) — **готово**;
- **Подменыши** — Changeling: The Dreaming 20th (4 книги) — **готово**.

Требования пользователя (соблюдать строго):
- **Механика — полностью и точно:** броски, сложности, затраты, длительность, таблицы успехов, цены. «Подробно, каждая сила должна быть расписана — это для моей системы».
- Всё **по-русски**, **своими словами**. Текст книг не копировать; художественный текст пересказать кратко или опустить. NPC-статистику не переписывать, но уникальные силы из сайдбаров NPC извлекать.
- Сообщения пользователю — **только по-русски**.
- **Не спрашивать разрешения на каждую книгу** — делать подряд.
- **Экономить токены.** Субагентов — максимум 2–3 одновременно, на дешёвой модели (Sonnet).
- **Новое указание пользователя (18.10): книги читать ПОЛНОСТЬЮ** (не только поиском), основную часть читать самому, агентам — остальное.

## 4. Как обрабатывать одну книгу

1. **Разметить книгу.** Найти главы и разделы поиском по txt, например `grep -n -i -E "^chapter|system:|difficulty|experience|pt\. (merit|flaw)|•" файл.txt`. Колонтитулы и номера страниц повторяются — фильтровать.
2. **Вырезать только разделы с механикой** (`sed -n 'A,Bp'`) во временный файл и читать кусками (у инструментов чтения лимит ~25 тыс. токенов за раз).
3. **Писать файлы** `_справочник/<Папка>/NN_Тема.md`, по 20–50 КБ, с описательными русскими именами. Если в книге механики нет — один короткий файл (3–5 строк) об этом.
4. **Записать книгу в `_прогресс.md`:** `- [x] <книга> → <папка>: файлы 01 (…), 02 (…)`.
5. **Обновить раздел 3 этого файла.**

Повреждённый текст передавать по смыслу, с пометкой «(в оригинале повреждено)»; сомнительное значение — с «?».

## 5. Формат файлов (общий для всех линеек)

## 9. Окружение и грабли (Windows)

- Windows 10. Есть Git Bash (`pdftotext` в /mingw64/bin) и PowerShell 5.1. Python 3.14 — запускать как `python -I`; установлен pymupdf.
- Писать файлы в UTF-8 **без BOM** и с переводами строк `\n`; в Python — `open(p, 'w', encoding='utf-8', newline='\n')`.
- Скрипты на Python — **отдельным файлом**, не `python -c "…"` и не через heredoc: обратные слэши в регулярках при этом ломаются, и регулярка молча ничего не находит.
- Не обрезать файл до того, как прочитан источник: открытие на запись сразу обнуляет файл.
- Не направлять долгие команды в `| head` — команда обрывается.
- Имена файлов на Windows регистронезависимы: перед записью проверять, что файла нет.
- В Git Bash кириллица в `grep`/`awk` иногда считается неверно — точный подсчёт делать в Python.
- Субагентов (если инструмент позволяет) запускать на дешёвой модели, по одному. Лимит сессии уже дважды обрывал большие пачки агентов.
