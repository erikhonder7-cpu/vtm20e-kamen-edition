# Справочник по книгам Mage: the Ascension 20th Anniversary (M20) и Victorian Age

Механика 14 книг M20 и викторианской линейки своими словами, по-русски. Броски, сложности, затраты, длительности и таблицы — полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Названия — «Русское (English)». Источник — английские тексты.

Как пользоваться ИИ — `AGENTS.md`. Термины — `Глоссарий_терминов.md`. Журнал разбора — `_прогресс.md`.

## Глоссарий
`Глоссарий_терминов.md` — термины M20 и Victorian Age (English | Русский | Пояснение), на основе Mage Translation Guide, с соответствиями Mage: the Awakening.

## Для ИИ
`AGENTS.md` — как пользоваться справочником, приоритеты, соглашения, известные пробелы.

## Указатель
- `Указатель.md` — алфавитный указатель эффектов, Чудес, Путей, достоинств и т. п. со ссылками.
- `Указатель_компактный.md` — сжатая версия (~25 тыс. токенов) для ИИ.

Пересборка (из папки `Маги/`):
```
python -I _скрипты/meta.py     # YAML-шапки
python -I _скрипты/index.py    # оба указателя
```

Сводные таблицы по трём линейкам — `../../Сводки/` (в т. ч. `Маги_Традиции_Конвенции_Ремёсла.md`), пробелы — `../../Пробелы_и_противоречия.md`.
