# Создание персонажа, Архетипы, Атрибуты, Способности — Mage Revised
**Источник:** Mage: The Ascension Revised Edition (RU, перевод), гл. 3 «Персонажи и Черты» (стр. 83–116)

## Пять шагов создания
Принципы: персонаж — недавно Пробудившийся «новичок» (за последние годы); числа вытекают из концепции; Рассказчик утверждает персонажа; рекомендуется Прелюдия (игровая сессия без кубиков о детстве/Пробуждении) и «Вопросы к персонажу».

| Шаг | Что делается |
|---|---|
| 1. Концепция | Концепция, Традиция, Энергия (Essence), Натура, Маска (Nature, Demeanor); (Кабал, Хроника) |
| 2. Атрибуты | три группы по приоритету **7 / 5 / 3** очков; у каждого Атрибута бесплатно **1** точка |
| 3. Способности | три группы **13 / 9 / 5**; начинаются с 0; **не выше 3** на этом шаге |
| 4. Преимущества | **7** очков Дополнений (Backgrounds); Фокусы выбираются бесплатно |
| 5. Завершение | **Арете 1**, **Сила Воли 5**, **Квинтэссенция = Аватар**, **Парадокс 0**; **15 Свободных очков**; Сферы: **1 в Родовой + 5 очков** (всего 6); Резонанс (1 точка в одной из трёх Черт) |

- Атрибуты — макс. 5 (предел человека); Способности ≤3 до трат Свободных очков. Сфера не может превышать Арете (ограничение при создании: Арете ≤3 за Свободные очки).
- Сироты/Пустые без Родовой Сферы: **6 очков** на любые Сферы.
- Если Родовая Сфера Традиции и фракции различаются — минимум 1 очко в Родовой Сфере Традиции («начальное обучение»).

### Стоимость Свободных очков (15)
| Черта | Цена |
|---|---|
| Атрибут | 5 за точку |
| Способность | 2 за точку |
| Сфера | 7 за точку |
| Дополнение | 1 за точку |
| Арете | 4 за точку (максимум 3) |
| Сила Воли | 1 за точку |
| Квинтэссенция | 1 очко за 4 пункта Квинтэссенции |

**Как в M20:** схема 7/5/3, 13/9/5, 7 Дополнений, 15 фриби — одинакова (см. `M20_Основная/01_Создание_персонажа.md`).
**Отличие от M20:** (1) в Revised **нет** Достоинств/Недостатков в основной схеме создания — они вынесены в Приложение (опциональные, `20`) и дают/стоят «Свободные очки»; (2) Родовая Сфера — «Сфера специализации», а не «Affinity»; (3) нет групповых ограничений на Сферы; (4) Дополнения не имеют «двойной цены»; (5) нет обязательных «инструментов» (7 штук) — в Revised Фокусы выбираются по одному на Сферу (см. ниже и файл `11`).

## Базовые концепции (подсказка)
Преступник, Бродяга, Артист, Интеллектуал, Следователь, Дитя, Человек Ночи, Аутсайдер, Политик, Профессионал, Репортёр, Светский Лев, Солдат, Рабочий (с примерами занятий).

## Энергия Аватара (Essence)
Четыре Энергии; пятая («Бесконечность») существует теоретически, у магов не встречается:
- **Динамика (Dynamic)** — перемены, новизна, непоседливость; Аватар в образе странной тени, меняющейся абстракции.
- **Узор (Pattern, = Статичность)** — порядок, стабильность, рационализм; авторитетные фигуры, механизмы.
- **Изначальность (Primordial)** — хаос, первобытные образы, сильные страсти; Аватар в облике животных, духов, богов.
- **Поиск (Questing)** — цель, баланс, странствия; Аватар часто похож на спутников мага.
Энергия определяет подход Аватара и «метафизические системы», с которыми маг взаимодействует легче; влияет на Искания.
Аватар проявляется во снах и порывах; редко — материализуется.

**Как в M20:** четыре Сущности, те же названия по смыслу (Dynamic, Static/Pattern, Questing, Primordial) — см. `M20_Основная/01`.

## Архетипы личности (Натура и Маска)
Натура — истинная суть; Маска — внешний образ. Действуя по Натуре, маг может **восстановить 1–2 очка временной Силы Воли**. Список (Revised) и условие восстановления:
| Архетип | Условие восстановления Силы Воли |
|---|---|
| Архитектор (Architect) | создаёт нечто важное и долговечное |
| Автократ (Autocrat) | принимает власть над новой группой/организацией |
| Гедонист (Bon Vivant) | по-настоящему веселится (особенно в компании) |
| Головорез (Bravo) | получает превосходство в долгом конфликте |
| Опекун (Caregiver) | защищает или воспитывает кого-либо |
| Проповедник (Celebrant) | всем сердцем следует страсти, убеждая других познакомиться с ней |
| Ребёнок (Child) | пробуждает чью-то мягкую, заботливую сторону |
| Соперничающий (Competitor) | побеждает в деле, требовавшем значительных усилий |
| Конформист (Conformist) | развивает цели группы, сподвигает на работу сообща |
| Плут (Conniver) | избегает работы или проблем, обманув другого |

| Девиант (Deviant) | выходит за границы без наказания |
| Командир (Director) | влияет на группу, организованно достигающую цели |
| Фанатик (Fanatic) | значительно продвигает своё дело |
| Щёголь (Gallant) | привлекает внимание заметным действием |
| Судья (Judge) | собирает факты воедино и разрешает загадку/проблему |
| Одиночка (Loner) | достигает значимого своими силами (особенно для Кабала/фракции) |
| Мученик (Martyr) | жертвует собой важным образом ради других |
| Мазохист (Masochist) | доводит себя до предела новым способом |
| Чудовище (Monster) | наслаждается особой жестокостью |
| Учитель (Pedagogue) | видит выгоду других от его знаний |

| Перфекционист (Perfectionist) | достигает значимого результата без колебаний и неудач |
| Бунтарь (Rebel) | его восстание приносит пользу |
| Норовистый (Rogue) | получает важное благодаря эгоцентричной природе |

Каждый Архетип имеет Силу и Слабость (напр., Архитектор: сила — Цель, слабость — Одержимость Амбициями); слабости — материал для Исканий. Названия русского перевода: Брюзга = Curmudgeon, Чудовище = Monster, Мастер Выживания = Survivor, Соперничающий = Competitor/Rival (в оригинале не ясно).

**Отличие от M20:** набор архетипов другой (в M20 ~20 других названий: Активист, Крестоносец, Пророк и т. д.); механика «Натура → Воля» совпадает.

## Атрибуты
Шкала: Х (0) отвратительно, ● плохо, ●● средне, ●●● хорошо, ●●●● превосходно, ●●●●● великолепно (предел человека). Девять Атрибутов:
- **Физические:** Сила (Strength), Ловкость (Dexterity), Выносливость (Stamina).
- **Социальные:** Обаяние (Charisma), Манипулирование (Manipulation), Внешность (Appearance).
- **Ментальные:** Восприятие (Perception), Интеллект (Intelligence), Сообразительность (Wits).
Специализации (Specialties) можно давать при ≥4, а ради детализации — и при меньших значениях (без механического бонуса). Примеры: Сила — Железная Хватка, Сильные Руки, Запас Сил, Кулаки-Молоты; Ловкость — Гибкость, Быстрота, Кошачья Грация, Молниеносные Рефлексы; Выносливость — Неутомимость, Крепок как Гвоздь, Устойчивый к Боли, Быстро Приспосабливающийся; Обаяние — Сексуальность, Чарующая Улыбка, Побуждение Защитить, Общественная Гибкость; Манипулирование — Убедительность, Соблазнительность, Аргументированность, Обвинитель, Обманщик, Ловкач; Внешность — Эротичность, Респектабельность, Эмоциональность, Загадочность, Земная Красота; Восприятие — Внимательность, Проницательность, Интуиция, Тщательность, Опытность; Интеллект — Созидательность, Аналитичность, Логичность, Хорошая Память, Авторитет в Предмете; Сообразительность — Всегда Готов, Остроумный Собеседник, Интуиция, Боевые Рефлексы.

Значимые описания:
- **Сила:** добавляется к кубикам урона в рукопашной. Подъём: 0 — 9 кг; 1 — 18 кг; 2 — 45 кг; 3 — 113 кг; 4 — 180 кг; 5 — 295 кг.
- **Манипулирование:** обман, блеф, давление; проваленный бросок может насторожить жертву. Обаяние — симпатия; Внешность — первое впечатление (бросок Внешность + Способность для первого впечатления, потом Обаяние/Манипулирование).
- **Интеллект** (IQ): 0 — 60; 1 — 80; 2 — 100; 3 — 120; 4 — 140; 5 — 160+. Интеллект = память, логика; Сообразительность = реакция под давлением; Восприятие = замечать детали.

## Способности (30)
Три группы по 10. Бросок обычно Атрибут + Способность. Шкала: ● Новичок, ●● Опытный, ●●● Компетентный, ●●●● Эксперт, ●●●●● Мастер. Подробные правила применения — `13`.

**Таланты (Talents)** — врождённые, интуитивные. Нет штрафа за отсутствие очков:
Бдительность (Alertness), Атлетизм (Athletics), Осведомлённость (Awareness), Драка (Brawl), Уклонение (Dodge), Экспрессия (Expression), Устрашение (Intimidation), Лидерство (Leadership), Знание Улиц (Streetwise), Хитрость (Subterfuge).
**Навыки (Skills)** — тренировка: Ремёсла (Crafts), Вождение (Drive), Этикет (Etiquette), Огнестрельное Оружие (Firearms), Медитация (Meditation), Фехтование/Ближний бой (Melee), Выступление (Performance), Незаметность (Stealth), Выживание (Survival), Техника (Technology). Использование без очков: возможен бросок только Атрибута, **сложность +1**.
**Знания (Knowledges)** — обучение: Академические Знания (Academics), Компьютеры (Computer), Космология (Cosmology), Загадки (Enigmas), Расследование (Investigation), Юриспруденция (Law), Языки (Linguistics), Медицина (Medicine), Оккультизм (Occult), Наука (Science). Без очков — **бросать нельзя** без разрешения Рассказчика.

Замечания по отдельным Способностям:
- **Осведомлённость (Awareness)** — интуитивное чувство магии, обычно только у магов и сверхъестественных существ; Рассказчик может бросать её тайно. Нужна для восприятия Резонанса (сложность 10 − Резонанс; см. `04`) и передач Квинтэссенции (6–10). Уровни: 1 — иногда чувствуете странное; 2 — «там что-то есть»; 3 — движение магии, иногда Резонанс; 4 — гул энергий; 5 — чувствуете заклинание на другом конце города, особенности Талисмана одним касанием.
- **Ремёсла (Crafts)** — при любом значении нужно выбрать Специализацию (бонус только при 4+).
- **Медитация (Meditation)** — используется для восстановления Квинтэссенции в Узле (Восприятие + Медитация, сложность 7; см. `04`) и Греза.
- **Фехтование (Melee)** и **Огнестрельное Оружие (Firearms)** — Revised-версии Навыков для атаки (см. `15`).
- **Языки (Linguistics):** родной язык бесплатно; каждое очко даёт доступ к новым языкам.
- **Науки (Science):** значения — Школьник, Студент, Магистр, Доктор, Учёный; сложность задаёт Рассказчик; практическое применение может потребовать Техники/Ремёсел.
- **Академические Знания:** простое знание — сложность 3–4; очень специфичное — 8–9; 1 успех — базовое знание, 3+ — подробности и список источников; допускается продолженный бросок (см. `13`).
- **Юриспруденция:** в сетях Традиции может отражать знание Протоколов и законов Традиций.

### Специализации (механика)
Если Атрибут или Способность ≥ 4 и в броске участвует область Специализации: можно **перебросить все выпавшие десятки** и прибавить результаты к успехам; повторная десятка снова перебрасывается; **провал при перебросе отменяет успех** («опасность чрезмерной уверенности»). Рассказчик может позволить **дополнительную Специализацию за каждое очко сверх 4** (при 5 очках — две).
**Отличие от M20:** в M20 Специализация при 4+ означает, что десятки считаются **двумя** успехами; в Revised — перебрасываемые десятки (взрывные) с отменой провалом.
Примеры Специализаций: Бдительность — Скрытое Оружие, Город, Лес, Слежка, Засады; Атлетизм — Акробатика, Танцы, Гибкость, определённый спорт; Драка — Бокс, Борьба, Разоружение, Грязные Приёмы, Пинки, Самооборона, определённое боевое искусство; Уклонение — Укрытие, Шаг в Сторону, Прыжок, Маневрирование; Экспрессия — Актёрство, Поэзия, Проза, Импровизация, Переговоры, Вдохновение; Устрашение — Пугающая Внешность, Твёрдость Характера, Блеф, Завуалированные Угрозы; Лидерство — Ораторство, Дружелюбие, Благородство, Напряжённые Ситуации; Знание Улиц — Слухи, Наркотики, Банды, Мелкие Кражи, Местный Сленг, Оружие; Хитрость — Соблазнение, Нераспознаваемая Ложь, Скрытые Эмоции, Политика; Осведомлённость — Талисманы, Духи, Эффекты, Магические Места, Резонанс; Космология — Имена Духов, Миры, Глубокая Умбра; Загадки — Дедукция, Головоломки, Исторические Головоломки, Коды и Тайнопись; Расследование — Судебная Экспертиза, Места Преступления, Яды, Оружие; Юриспруденция — Уголовное, Гражданское, Традиции, Полицейские Процедуры, Контракты; Медицина — Исследования, Педиатрия, Неотложная Помощь, Патологии, Отравления, Хирургия, Фармацевтика; Оккультизм — Вуду, Ведьмовство, Призраки, Мифы о Смерти, Инфернализм, New Age, Фольклор; Наука — Химия, Биология, Геология, Авиатехника, Астрономия, Металлургия, Физика; Техника — Электроника, Механика, Двигатели; Компьютеры — Программирование, Взлом.

## Сферы при создании (напоминание)
Все девять: Связи (Correspondence), Энтропия (Entropy), Силы (Forces), Жизнь (Life), Материя (Matter), Разум (Mind), Основы (Prime), Дух (Spirit), Время (Time). Начальный балл — 1 в Родовой Сфере; ещё 5 очков; уровень Сферы ≤ Арете. Подробности — `05`–`12`.

## Фокус при создании
Фокусы не стоят очков: **для каждой Сферы** выбирается один Фокус (предмет или метод) из набора Традиции. Это тот же «фокус» Revised (подробности и ограничения — `11`). Без подходящего Фокуса маг вообще не может творить магию.
