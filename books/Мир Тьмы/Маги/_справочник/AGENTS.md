# Инструкция для ИИ: как использовать этот справочник

Справочник механики Mage: the Ascension 20th Anniversary (M20) и викторианской линейки (M20 Victorian Age) на русском языке: создание персонажа, Сферы, магия и Парадокс, фокус (парадигмы, практики, инструменты), эффекты (ротэ), Чудеса, Факты биографии, достоинства и недостатки, бой, Технократия, Нефанди, компаньоны и духи, линейная магия смертных (Sorcerer). Собран из 14 книг (65 файлов). Механика передана полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Цель — встроить данные в игровую систему (вместе с V20 и W20 — см. `../../CLAUDE.md`).

## С чего начать
1. **`Указатель_компактный.md` (~25 тыс. токенов) — держите его в контексте как карту.** Все записи указателя по строке, файлы под номерами (расшифровка — в разделе «Файлы»). Нужный файл открывайте по номеру; полный `Указатель.md` целиком читать незачем.
2. `README.md` — содержание по книгам: какой файл что содержит.
3. `Глоссарий_терминов.md` — термины: English | Русский | Пояснение (основа — Mage Translation Guide; есть соответствия Mage: the Awakening).
4. Базовая механика: `M20_Основная/01` (создание и опыт), `02a`/`02b` (Сферы), `03` (магия и Парадокс), `04` (фокус), `08a`–`08d` (система, бой, среда, Способности).
5. `_прогресс.md` — журнал разбора книг (какая книга в какой папке).

## Метаданные файла
У каждого файла в начале YAML-шапка:

```yaml
book: "M20 How Do You DO That?"   # книга-источник (англ. название)
edition: "M20"                    # редакция: M20 или M20 Victorian Age
compat_m20: "native"              # совместимость с M20
source: "official_en"             # откуда взят текст
reliability: "high"               # насколько точны числа
```

| Поле | Значения |
|---|---|
| `edition` | `M20`; `M20 Victorian Age` (папки `M20_Victorian_Age`, `M20_VA_*`); `mixed` (глоссарий) |
| `compat_m20` | `native` — правила M20 как есть; `minor` — старая редакция или фанатское (сверять с M20); `convert` — другая система (например, Mage: the Awakening); `none` — другая игра |
| `source` | `official_en` — официальный английский текст; `compiled` — собрано проектом |
| `reliability` | `high` — числа надёжны; `medium` — возможны неточности; `low` — источник сбитый |

## Правила приоритета
- **Основа — основная книга M20.** Book of Secrets уточняет и расширяет её (там же FAQ по правилам — `M20_Book_of_Secrets/10`). How Do You DO That? — примеры эффектов, а не обязательный список: эффект с теми же Сферами можно собрать и иначе.
- **Victorian Age** — дополнение той же системы для XIX века: свои способности, Фоны, виды магии (изящная, жуткая, катастрофическая), Теснины вместо современного Парадокса в ряде случаев. В современную хронику не переносить без решения ведущего.
- **Sorcerer** — линейная магия и психические феномены **смертных** (не пробуждённых), отдельная от Сфер система.
- Машинные переводы в `../_текст/Машинный_перевод_RU/` — **не источник**, только для сверки терминов.
- Стыковка с вампирами (V20) и оборотнями (W20) — `../../CLAUDE.md`, «Памятка 2».

## Соглашения в тексте
- Название: «Русское (English)». Английское название — самый надёжный ключ для сопоставления.
- Эффекты: `- **Русское (English)** (Сферы: Разум 2, Дух 1) — …`.
- Сферы: Соответствие (Correspondence), Энтропия (Entropy), Силы (Forces), Жизнь (Life), Материя (Matter), Разум (Mind), Первоначало (Prime), Дух (Spirit), Время (Time).
- Таблицы достоинств и недостатков: `| Название | Цена | Эффект |`.
- «как в …» — правило совпадает с указанным местом, повторно не расписано.
- `(раб.)` — рабочий перевод проекта; `?` — значение предположительное; «(в оригинале повреждено)» — дыра в источнике.

## Разные русские названия одного и того же
Сопоставляйте по английскому названию. Принятые формы — первые.

| Английский | Принято / встречается |
|---|---|
| Affinity Sphere | родовая Сфера; родственная Сфера (Victorian Age) |
| Prime | Первоначало |
| Rote | ротэ |
| Wonder / Talisman / Trinket | Чудо / Талисман / Безделушка |
| Quiet | Безмолвие |
| Gauntlet | Преграда |
| Blatancy | Откровенность, Явность |
| Adjustments | Подстройки |
| Requisitions | Реквизиции, Снабжение |
| Warding | Обереги, Защита |
| Essence (Avatar) | Сущность (Аватара) |
| Charm (spirit) | Чара, Амулет |
| Derangements | расстройства (не «деранжировки») |
| Disparates / Crafts | Дисперсные Ремёсла |
| Great Work | Великое Деяние |

Остальные пары с несколькими вариантами — раздел «Английский → несколько русских вариантов» в `Указатель_компактный.md` и `Глоссарий_терминов.md`.

## Известные пробелы
Полный список с номерами строк — `../../Пробелы_и_противоречия.md`, раздел «Маги». Главное:
- `M20_Victorian_Age/04` — таблицы оружия: колонки в источнике перемешаны; Гатлинг, «Апач»-револьвер и дробовики приблизительны; у рукопашного оружия нет сложности.
- `M20_Victorian_Age/01` — нет описания Достоинства связи с тайными обществами; родственные Сферы Ву Лун и части Ремёсел неполны.
- `M20_VA_Weird_Wonders/01` — вёрстка перемешала часть описаний; у части Чудес не указан уровень; названия категорий — рабочий перевод.
- `M20_Sorcerer/03`, `04` — неразборчивые ранги Оборотничества; перемешанные колонки у части психических феноменов.
- `M20_Gods_and_Monsters/01`, `M20_Faces_of_Magick/01` — русские названия части Достоинств приблизительны.
- `M20_Основная/01` — одна строка таблицы опыта восстановлена по правилам.
- Статистика NPC сознательно не переписывалась.

Найти все такие места: поиск по строкам `повреждено`, `приблизительн`, `?)`.

## Исходники и скрипты (в соседних папках, если переданы)
- `../_текст/M20/`, `../_текст/M20_Victorian_Age/` — извлечённый текст книг (для сверки).
- `../_скрипты/meta.py` — проставить YAML-шапки (по словарю FOLDERS); `index.py` — пересобрать оба указателя.

## Рекомендуемый порядок встраивания
1. Ядро: `M20_Основная/` — 01, 02a, 02b, 03, 04, 08a–08d, затем 05, 06, 07, 09.
2. Расширения правил: `M20_Book_of_Secrets/`, `M20_How_Do_You_DO_That/` (примеры эффектов).
3. Фракции: `M20_Lore_of_the_Traditions/`, `M20_Technocracy_Reloaded/`, `M20_Operatives_Dossier/`, `M20_Book_of_the_Fallen/`.
4. Компаньоны и смертная магия: `M20_Gods_and_Monsters/`, `M20_Sorcerer/`.
5. Выборочно: `M20_Rich_Bastards_Guide/`, `M20_Faces_of_Magick/`.
6. Отдельный сеттинг XIX века: `M20_Victorian_Age/`, `M20_VA_Weird_Wonders/`, `M20_VA_Bizarre_Tales/`.
