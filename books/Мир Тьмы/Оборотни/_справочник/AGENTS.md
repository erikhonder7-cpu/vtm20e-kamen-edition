# Инструкция для ИИ: как использовать этот справочник

Справочник механики Werewolf: the Apocalypse 20th Anniversary (W20) на русском языке: создание персонажа, породы, аугурии, племена, Дары, ритуалы, фетиши и талены, Слава и Ранг, Ярость и Гнозис, бой, Умбра и духи, Фера, враги (Червь, фомори, Pentex), достоинства и недостатки. Собран из 11 книг W20 (50 файлов). Механика (броски, сложности, затраты, длительности, таблицы) передана полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Цель — встроить данные в игровую систему (вместе с V20 и M20 — см. `../../CLAUDE.md`).

## С чего начать
1. **`Указатель_компактный.md` (~25 тыс. токенов) — держите его в контексте как карту.** Все записи указателя по строке, файлы под номерами (расшифровка — в разделе «Файлы»). Нужный файл открывайте по номеру; полный `Указатель.md` (~2850 строк) целиком читать незачем.
2. `README.md` — содержание по книгам: какой файл что содержит.
3. `Указатель.md` — алфавитный указатель Даров, ритуалов, фетишей, таленов, достоинств и недостатков со ссылками; в конце — «English → русский».
4. `Глоссарий_терминов.md` — основные термины: английский → русский.
5. Базовая механика: `W20_Основная/01` (создание), `09` (опыт, Слава, Ранг, Ярость, Гнозис), `10` (правила, урон, формы, бой), `11` (Умбра и духи).

## Метаданные файла
У каждого файла в начале YAML-шапка:

```yaml
book: "W20 Changing Breeds"   # книга-источник (англ. название)
edition: "W20"                # редакция правил
compat_w20: "native"          # совместимость с W20
source: "official_en"         # откуда взят текст
reliability: "high"           # насколько точны числа
```

| Поле | Значения |
|---|---|
| `edition` | `W20` (у всех книг), `mixed` (глоссарий) |
| `compat_w20` | `native` — правила W20 как есть; `minor` — старая редакция или фанатское (сверять с W20); `convert` — другая система; `none` — другая игра |
| `source` | `official_en` — официальный английский текст (у всех книг); `compiled` — собрано проектом (глоссарий) |
| `reliability` | `high` — числа надёжны; `medium` — возможны неточности; `low` — источник сбитый |

## Правила приоритета
- **Основа — основная книга W20.** Дополнения (Changing Breeds, Kinfolk, Changing Ways, Umbra и др.) расширяют её; при расхождении одной и той же силы приоритет у основной книги, если в дополнении прямо не сказано, что правило заменяется.
- Старых редакций оборотней (1st, 2nd, Revised) в справочнике нет.
- `W20_Pentex/` — в книге нет механики, файл только отмечает это.
- `W20_Shattered_Dreams/` — правила для игры в прошлые эпохи; в современную хронику переносить выборочно.
- Стыковка с вампирами (V20) и магами (M20) — `../../CLAUDE.md`, «Памятка 2».

## Соглашения в тексте
- Название: «Русское (English)». Английское название — самый надёжный ключ для сопоставления.
- Дары: `## Племя / порода / аугурия` → `### Уровень N` → `- **Русское (English)** — кто учит (дух). Механика…`.
- Ритуалы и фетиши: `- **Русское (English)** — ур. N[, Гнозис N]. …`.
- Таблицы достоинств и недостатков: `| Название | Цена | Эффект |`.
- Урон: ударный (bashing), летальный (lethal), губительный (aggravated).
- «как у …» / «как в …» — правило совпадает с указанным местом, повторно не расписано.
- `(раб.)` — рабочий перевод проекта; `?` — значение предположительное; «(в оригинале повреждено)» — дыра в источнике.

## Разные русские названия одного и того же
Сопоставляйте по английскому названию. Принятые в справочнике формы — первые.

| Английский | Принято / встречается |
|---|---|
| Bane | **Бейн**, Бейны (не «Бан»: Ban — запрет тотема) |
| Ban | запрет (тотема) |
| Gauntlet | Преграда |
| Veil | Завеса (тайна от людей; не путать с Преградой) |
| Delirium | Бред (Делириум) |
| Kinfolk | Родня |
| Crinos | **Кринос** (в черновиках была опечатка «Крииос») |
| Renown: Glory / Honor / Wisdom | Слава: Слава / Честь / Мудрость |
| Primal-Urge | Первобытный инстинкт |
| Enigmas | Загадки |
| Frenzy | бешенство |
| Wyrm / Weaver / Wyld | Червь / Ткачиха / Дикость |
| Philodox | Филодокс, Философ |
| Balefire | Балефайр, Огонь скверны |
| Changing Breeds | Фера, Изменяющиеся роды |
| Derangements | расстройства |

Остальные пары с несколькими вариантами — раздел «Английский → несколько русских вариантов» в `Указатель_компактный.md`.

## Известные пробелы
Сомнительные и повреждённые места (полный список с номерами строк — `../../Пробелы_и_противоречия.md`, раздел «Оборотни»):
- `W20_Kinfolk/01` — стоимость в опыте и пара строк таблиц не сохранились.
- `W20_Shattered_Dreams/01` — числа в таблице степеней (Пустяковый, Малый и т. п.).
- `W20_Основная/09`, `10` — по одному-два места.
- `W20_Changing_Breeds/03_Бастет` — одно место.
- Статистика NPC и духов (стат-блоки) сознательно не переписывалась.

Найти все такие места: поиск по строкам `повреждено`, `?)`.

## Исходники и скрипты (в соседних папках, если переданы)
- `../_текст/` — извлечённый текст книг (для сверки).
- `../_скрипты/meta.py` — проставить YAML-шапки (по словарю FOLDERS); `index.py` — пересобрать оба указателя; `bane_term.py <папки>` — заменить «Бан» на «Бейн» в новых файлах.

## Рекомендуемый порядок встраивания
1. Ядро: `W20_Основная/` — 01, 09, 10 (система и бой), затем 03–08 (Дары, ритуалы, фетиши), 14 (достоинства), 02 (Факты), 11–13 (Умбра, союзники, враги).
2. Расширения игроков: `W20_Changing_Ways/`, `W20_Kinfolk/`, `W20_Changing_Breeds/` (если нужны Фера).
3. Мир и противники: `W20_Umbra/`, `W20_Book_of_the_Wyrm/`, `W20_Rage_Across_the_World/`.
4. Выборочно: `W20_White_Howlers/`, `W20_Shattered_Dreams/`, `W20_Skinner/`.
