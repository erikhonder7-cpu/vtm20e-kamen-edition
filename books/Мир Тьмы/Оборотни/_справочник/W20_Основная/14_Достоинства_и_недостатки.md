# Достоинства и недостатки, умопомешательства — основная книга W20

**Источник:** Werewolf: The Apocalypse 20th Anniversary Edition (EN), Appendix, стр. 470–486.

## Общие правила
- Достоинства (Merits) и недостатки (Flaws) — необязательные Черты; Рассказчик может их запретить, ограничить или добавить свои.
- Выбираются **только при создании** (за свободные очки; Рассказчик может позже убрать/добавить в ходе хроники). Достоинство стоит указанное число свободных очков; **недостаток даёт столько же свободных очков**, но не более **7** очков недостатков. 15 свободных очков создания + 7 = до 22.
- Категории: физические, умственные, социальные, сверхъестественные.
- Для метисов многие физические недостатки («Деформация», «Хромой», «Чудовищный», «Одна рука», «Глухой», «Немой», «Слепой») можно взять **бесплатно** как врождённое уродство метиса.

## Физические достоинства
| Название | Цена | Эффект |
|---|---|---|
| Острое чувство (Acute Sense) | 1 | Один чувство (зрение, слух, обоняние, осязание, вкус): сложности его бросков −2. Можно брать для разных чувств; в броске применяется одно такое снижение; нельзя, если чувство нарушено недостатком |
| Стойкость к алкоголю (Alcohol Tolerance) | 1 | Стойкость сл. 7: игнорировать опьянение (от природных интоксикантов, даже переработанных, но не ядов и синтетических наркотиков) |
| Обоерукость (Ambidextrous) | 1 | Без штрафа действовать «не той» рукой и двумя оружиями (правило нескольких действий действует) |
| Гибкие суставы (Double-Jointed) | 1 | Броски на гибкость (вырваться из захвата) −2 к сложности |
| Смешанная форма (Mixed-morph) | 1 или 5 | Частичное превращение: Ловкость + Первобытный инстинкт сл. **6** вместо 9; за 5 очков — не нужна ещё и трата Воли |
| Совершенное равновесие (Perfect Balance) | 1 | Броски на равновесие −2 к сложности |
| Волчье зрение (Wolf Sight) | 1 | Видит как волк: +1 кубик к зрительным Восприятиям, связанным с движением или ночью |
| Дурной вкус (Bad Taste) | 2 | Укусивший (вампир, Гару, фомор, тварь Червя) тошнит: тратит Волю или блюёт сцену; лупусы/волки не вылизывают |
| Приличное Глабро (Fair Glabro) | 2 | Глабро выглядит как человек, без штрафов Социальным Атрибутам |
| Отсутствие запаха (Lack of Scent) | 2 | Выслеживание по запаху +2 к сложности; волки/лупусы не доверяют |
| Физически впечатляющий | 2 | +1 кубик к социальным броскам на запугивание |
| Сорвиголова (Daredevil) | 3 | В исключительно рискованных небоевых действиях +3 кубика и можно отменить один кубик фиаско (нужна сл. ≥8 и угроза ≥3 уровней урона) |
| Бегун на длинные (Long-Distance Runner) | 3 | Бежит с двойной скоростью час за каждую точку Стойкости; нужна Стойкость ≥4 |
| Природное оружие (Natural Weapons) | 3 или 4 | В Лупусе −1 к сложности атак природным оружием (коготь, укус, пинок); в Хомиде +1; 3 очка для лупусов и метисов, 4 для хомидов |
| Огромный размер (Huge Size) | 4 | ~2,1 м и до 180 кг в Хомиде; доп. уровень здоровья (как лишний «Помят») |
| Метаморф (Metamorph) | 7 | Смена форм без броска и без траты Ярости — будто 5 успехов; при потере сознания можно выбрать форму броском Смекалка + Первобытный инстинкт сл. 8 вместо возврата в породную |

| Метка хищника | 2 | Травоядные бегут, хищники вызывают; нет Обращения с животными |
| Знак волка (Sign of the Wolf) | 2 | Сросшиеся брови, волосы на ладонях, пентаграмма в фазе луны; охотники узнают |
| Дырявая Завеса (Pierced Veil) | 3 | Ваш Кринос не вызывает Бред |
| Склонность к Харано (Harano Prone) | 4 | Бросок Воли в каждой сцене с неудачей; провал — временное Харано (теряет 1 кубик на каждый пул; мрачен или самоубийственно активен); фиаско — временное безумие; Воля откладывает на сцену |
| Тёмный рок (Dark Fate) | 5 | Предопределённая гибель в ходе хроники; видения; Воля временно подавляет |
| Печать скверны (Taint of Corruption) | 7 | «Чутьё Червя» показывает сильное осквернение; Ритуал Очищения не помогает; сопротивление силам Червя (фомори, Дары Танцоров, Обаяния Бейнов, Дисциплины вампиров) +2 к сложности; избавиться — большое задание |

## Умопомешательства (Derangements)
Выбираются Рассказчиком с игроком по Натуре; лечатся с трудом (мощные Дары, ритуалы). Танец Чёрной Спирали вызывает их.
| Название | Механика |
|---|---|
| Фуга (Fugue) | В сильном стрессе — Воля сл. 8, иначе транс (как лунатизм): Рассказчик управляет персонажем число сцен = 1 d10; потом без памяти |
| Истерия (Hysteria) | Резкие перепады настроения; при сильном стрессе — бросок на бешенство, сложность бешенства −2 |
| Множественные личности | Несколько личностей, не знающих друг о друге; триггеры и Способности определяются с Рассказчиком |
| Обсессивно-компульсивное | Потребность в порядке/ритуале; после триггера — только он; чтобы делать иное, нужна 1 Воля за сцену |
| Паранойя (Paranoia) | Социальные броски +1 к сложности; подозрительные действия (подмена еды, вторжение) → бросок на бешенство |
| Шизофрения | В триггерных ситуациях сложности сопротивления бешенству +3 и −3 кубика на все броски Воли |

## Натура и Образ (Nature and Demeanor) — необязательное правило
**Натура** — истинное лицо, **Образ** — маска. Если Рассказчик принял формально, то каждый раз, выполнив условие Натуры, персонаж может восстановить 1 потраченную Волю.

| Архетип | Восстановление 1 Воли, когда… |
|---|---|
| Альфа (Alpha) | получил контроль над группой/организацией или заставил соперника подчиниться |
| Архитектор (Architect) | создал нечто важное и долговечное |
| Торгаш (Barterer) | получил значимый ресурс (фетиш, услугу) по выгодной цене |
| Большой Злой Волк (Big Bad Wolf) | кто-то отшатнулся от вас в страхе |
| Бонвиван (Bon Vivant) | по-настоящему развлёкся (грандиозное празднество — несколько очков) |
| Задира (Bravo) | добился цели грубостью/запугиванием |
| Опекун (Caregiver) | успешно защитил или выходил кого-то |
| Энтузиаст (Celebrant) | занялся своим делом или обратил другого; **теряет** 1 временную Волю, если лишён страсти |
| Соперник (Competitor) | преуспел в испытании (трудные победы — несколько очков) |
| Конформист (Conformist) | группа/лидер достигли цели благодаря вашей поддержке |
| Интриган (Conniver) | обманом заставил кого-то сделать для вас или против его интересов |
| Упрямец (Contrary) | нарушил общественные нормы без последствий |
| Детёныш (Cub) | убедил кого-то заботиться о вас или помочь без выгоды |
| Директор (Director) | повлиял на группу/личность, помог выполнить трудную задачу |
| Фанатик (Fanatic) | выполнил задачу, связанную с делом |
| Фаталист (Fatalist) | вслух предсказал неудачу, и она случилась |
| Щёголь (Gallant) | произвёл впечатление на другого |
| Гуру (Guru) | вас просили о духовной помощи и ваше слово привело к просветлению; или у вас эпифания |
| Идеалист (Idealist) | действие в духе идеалов приблизило цель |
| Судья (Judge) | верно решил задачу по доказательствам или объединил спорящих |
| Одиночка (Loner) | добился чего-то в одиночку, что всё же помогло группе |
| Педагог (Pedagogue) | узнал о том, кому ваша мудрость помогла |
| Мученик (Martyr) | пострадал/потерял ресурс ради идеалов или чужой выгоды |
| Кающийся (Penitent) | достиг искупления за проступок (искупление соразмерно вине; судит Рассказчик) |
| Перфекционист (Perfectionist) | достиг цели без изъянов или вдохновил другого на успех |
| Бунтарь (Rebel) | действия ударили по выбранному противнику |
| Негодяй (Rogue) | своекорыстие принесло выгоду; также если вы помогли своей группе за счёт другой |
| Учёный (Scientist) | логичный подход решил задачу |
| Солдат (Soldier) | выполнил цели приказа (сложнее — больше удовлетворения) |
| Выживший (Survivor) | пережил угрозу упорством или убедил другого продолжать |
| Искатель острых ощущений | преуспел в сознательно опасном деле |
| Традиционалист (Traditionalist) | проверенный путь оказался лучшим, или придерживался прежней позиции и это оказалось мудро |
| Трикстер (Trickster) | поднял другим настроение, облегчив и собственную боль |
| Визионер (Visionary) | убедил других поверить в мечту и следовать видению |
