# Справочник по книгам Werewolf: the Apocalypse 20th Anniversary (W20)

Механика 11 книг W20 своими словами, по-русски. Броски, сложности, затраты, длительности и таблицы — полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Названия — «Русское (English)». Все книги одной редакции W20, источник — английские тексты.

Как пользоваться ИИ — `AGENTS.md`. Термины — `Глоссарий_терминов.md`.

## Глоссарий

## Для ИИ
`AGENTS.md` — как пользоваться справочником, приоритеты, соглашения, известные пробелы.

## Указатель
- `Указатель.md` — алфавитный указатель всех Даров, ритуалов, фетишей, достоинств и т. п. со ссылками; в конце — «English → русский».
- `Указатель_компактный.md` — тот же указатель в сжатом виде (~25 тыс. токенов) для ИИ.

Пересборка (из папки `Оборотни/`):
```
python -I _скрипты/meta.py        # YAML-шапки
python -I _скрипты/bane_term.py <папки>   # выравнивание «Бан» → «Бейн» в новых файлах
python -I _скрипты/index.py       # оба указателя
```

Сводные таблицы по трём линейкам — `../../Сводки/` (в т. ч. `Оборотни_Дары_по_уровням.md`), пробелы — `../../Пробелы_и_противоречия.md`.
