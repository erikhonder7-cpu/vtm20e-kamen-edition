# Справочник «Мир Тьмы» для своей системы (V20 + W20 + M20 + Wraith 20 + C20)

Этот файл для Claude Code в проекте Камня. Камень пишет свою систему по **VtM V20**. В той же системе будут **оборотни (W20)** и **маги (M20, плюс Викторианская эпоха)**, **призраки (Wraith 20)** и **подменыши (C20)**, а также контент старых редакций вампиров. Справочник — пересказ механики книг на русском: броски, сложности, затраты, длительности и таблицы полностью, художественный текст сокращён или опущен, статистика NPC не переписана.

Скопируй этот файл в корень своего проекта. Папку `Мир Тьмы/` положи рядом или поправь пути ниже.

## YAML-шапка каждого файла

```yaml
book: "V20 Lore of the Clans"   # книга (англ.)
edition: "V20"                  # редакция
compat_v20: "native"            # у оборотней compat_w20, у магов compat_m20, у призраков compat_wraith20, у подменышей compat_c20
source: "official_ru"           # official_en/ru, fan_translation_ru, machine_translation_ru, ocr_en, summary_ru, compiled
reliability: "high"             # high / medium / low — насколько надёжны числа
```

`compat_*`: `native` — правила 20-летия как есть; `minor` — старая редакция или фанатское, та же система, числа сверять; `convert` — другая система (V5), нужна конверсия; `none` — другая игра (nWoD), **не смешивать**.

## Приоритет источников

1. **Числа 20-летних редакций главные:** V20 / W20 / M20 / Wraith 20 / C20. Если сила, достоинство или правило есть в книге 20-летия — брать оттуда.
2. Для эпох: V20 Dark Ages (Тёмные века, своя система Дорог); M20 Victorian Age (Викторианская эпоха магов) — дополнение к M20, не замена.
3. Revised (1998–2004) → 2nd Edition (1992–97) → 1st → фанатское: **только как дополнительный контент**, переводить на V20 по памятке ниже.
4. `compat: none` (nWoD) и `convert` (V5, Fall of London) — идеи для сюжета, а не механика.
5. Машинный перевод (`machine_translation_ru`) — термины бывают сбиты, сверять по английскому названию.

## Соглашения текста

- Названия: «Русское (English)». **Английское название — главный ключ** для сравнения книг, потому что русские переводы называют одно и то же по-разному (Затмение = Власть над Тенью; Сокрытие = Затемнение и т. п. — таблица в `Вампиры/_справочник/AGENTS.md`).
- `?` — значение предположительное; «(в оригинале повреждено)» — дыра в источнике; `(раб.)` — рабочий перевод проекта.
- Достоинства и недостатки: `| Название | Цена | Эффект |`.

## Памятка 1. Перенос старых редакций вампиров на V20

### Способности

| Старое (1st / 2nd / Revised) | В V20 | Примечание |
|---|---|---|
| Acting / Актёрство (2nd) | Исполнение (Performance) или Хитрость (Subterfuge) | игра на сцене — Исполнение, притворство — Хитрость |
| Music / Музыка (2nd) | Исполнение (Performance) | |
| Expression (Revised) | Красноречие (Expression) | то же |
| Dodge / Уклонение (2nd, Revised) | **нет** → уклонение = Ловкость + **Атлетика** | частая ошибка при переносе пулов |
| Security / Безопасность | Воровство (Larceny) | |
| Repair / Ремонт (2nd) | Ремесло (Crafts) или Электроника (Technology) | |
| Bureaucracy / Бюрократия | Политика (Politics) или Законы (Law) | |
| Linguistics / Лингвистика | в V20 нет как способности → достоинство или знание языков по решению рассказчика ? | проверить в `Достоинства_и_недостатки/` |
| — | Шестое чувство (Awareness), Электроника (Technology) | новые в V20 |
| Вторичные способности (Players Guide 2nd: Кутёж, Торг, Акробатика, Гипноз, Психоанализ и др.) | Хобби / Профессия / Квалификация (Hobby Talent, Professional Skill, Expert Knowledge) или специализации | механику бросков можно брать из `Revised_Основные/02a` |
| Charisma = «Харизма», Streetwise = «Знание улиц» (фанатские переводы) | Обаяние, Уличное чутьё | только названия |

### Опыт и свободные пункты

- Брать **только таблицу V20** (`V20_Основные_правила/01`): новая способность 3, новая Дисциплина 10, новый путь магии крови 7; характеристика ×4, способность ×2, клановая Дисциплина ×5, чужая ×7, каитиф ×6, вторичный путь ×4, Добродетель ×2, Человечность/Путь ×2, воля ×1.
- Свободные пункты V20: Человечность/Путь стоят **2** (в Revised 1). Дисциплина 7, характеристика 5, способность 2, факт 1, Добродетель 2, воля 1.
- Цена **комбинированных сил** и **высших уровней** из старых книг (кланбуки Revised, гайды сект) — ориентир. Если та же сила есть в V20-книге (`Lore_of_the_Clans`, `Lore_of_the_Bloodlines`, `Дисциплины/`), брать V20. Пример: «Блаженство (Bliss)» — 15 опыта в Lore of the Clans, 14 в кланбуке Тореадора Revised → **15**.

### Силы 6–10 уровня

- Players Guide 2nd (`Revised_Основные/02a`, `02b`), `Revised_Гайды_сект/01c`, `DA_High_Clans/`, `DA_Low_Clans/` дают силы 6–10 с правилом «на каждом уровне выбор из нескольких сил». В V20 высшие силы есть в `Дисциплины/` (основная книга) и `Lore_of_the_Clans`.
- Если одноимённые силы расходятся, брать V20.
- **Пример расхождения** — «Любовь (Love)», Величие 6:
  - V20: 1 кровь, Обаяние + Хитрость, сложность — воля жертвы; каждый успех −1 кубик к социальным броскам жертвы против вампира; длится сцену; провал — иммунитет к Величию до конца ночи.
  - PG 2nd: бесплатно, Обаяние + Актёрство, эффект уз, пока жертва рядом.
- Предел уровня Дисциплины задаёт поколение (V20: 8-е → 5, 7-е → 6 … 4-е → 9).

### Урон

| Редакция | Как | Перевод на V20 |
|---|---|---|
| 1st / 2nd | урон в основном «обычный» (вампир поглощает выносливостью) и губительный | кулаки и дубины → **лёгкий**; клинки, когти смертных, огнестрел по смертным → **тяжёлый**; огонь, солнце, клыки и когти сверхъестественных → **губительный** |
| Revised | ударный / летальный / губительный, огнестрел по вампирам — летальный | в V20 огнестрел по вампиру **лёгкий** (в голову — тяжёлый); лёгкий урон у вампира делится пополам после прочности |
| Dark Ages | как Revised, свои таблицы оружия | для Тёмных веков — по `V20_Dark_Ages/` |

### Поколения, кровь, Пути

- Таблица поколений одинакова в Revised и V20 (предел параметра, запас, трата за ход). 14-е и 15-е поколения в V20 — недостатки.
- **Пути Просветления:** Добродетели и Иерархии грехов в V20 (`V20_Основные_правила/06`) главные. Старые версии — `Revised_Гайды_сект/03d` (Шабаш 1999) и `04c` (1992), `Revised_Основные/02a` (Тифон и Парадокс 2nd).
- Пути, которых нет в основной книге V20, сначала искать в V20-дополнениях (`Сводки/Вампиры_Пути_и_Дороги.md`): например, Путь Злых Откровений есть в `Dread_Names/01`, Пути Воина, Экстаза и Энтелехии — в `Lore_of_the_Clans`. Если Путь есть только в старой книге, при переносе дать ему **столп** (bearing) по образцу V20.
- Путь Гармонии (1992) = Дикое Сердце с совестью вместо решимости.
- Старое «Убеждённость» = V20 «Решимость» (Conviction).
- Дороги Тёмных веков (`V20_Dark_Ages/`) — отдельная система, в современную хронику не переносить без решения ведущего.

## Памятка 2. Стыковка линеек в одной системе

Общее у V20, W20 и M20: d10, сложность 2–10 (по умолчанию 6), «1» отменяет успех, провал (ботч), воля (1 пункт — автоуспех, не больше 1 за ход), продолжительные, встречные и командные действия, 7 уровней здоровья с штрафами −1/−1/−2/−2/−5, типы урона «ударный (лёгкий) / летальный (тяжёлый) / губительный», инициатива Ловкость + Смекалка + 1d10.

**Различия, которые надо свести:**

| Тема | Вампир (V20) | Оборотень (W20) | Маг (M20) |
|---|---|---|---|
| Прочность против летального | выносливость (+ Стойкость) | выносливость (сл. 6) во всех формах, кроме породной | как смертный: **только ударный**, летальный — броня или магия (Жизнь) |
| Прочность против губительного | только Стойкость | выносливость (сл. 6) во всех формах, кроме породной; губительный не регенерирует | только магия или Дары и т. п. |
| Особая уязвимость | огонь, солнце (губит.), кол (паралич) | **серебро** (губит., не поглощается, кроме породной формы хомида или лупуса) | Парадокс |
| Лечение | кровь: 1 пункт = 1 лёгкое или тяжёлое; губительное — 5 пунктов + сутки | регенерация 1 уровня в ход (в стрессе — выносливость сл. 8); губительное лечится медленно | как смертный или магия Жизни |
| «Топливо» | запас крови (по поколению) | Ярость (доп. действия), Гнозис (Дары, Умбра) | Арете (сила магии), Квинтэссенция, Парадокс |
| Доп. действия | Стремительность (точки = действия) | Ярость (пункт = действие) | магия Времени |
| Мораль и срывы | Человечность/Путь, ярость, Ротшрек | Слава и Ранг, бешенство (Ярость), Харано | Резонанс, Сплетения Парадокса, Тишина |
| Опыт | своя таблица (V20/01) | своя таблица (`W20_Основная/09`) | своя таблица (`M20_Основная/01`: Сфера родовая ×7, прочая ×8, Арете ×8) |
| Кровь как пища | 10 у человека | **20 пунктов** в оборотне (сильная кровь) | 10, как у человека |

**Перекрёстные правила из V20:**
- клыки и когти оборотня по вампиру — губительные;
- укус вампира по Гару — губительный;
- кровь оборотня — 20 пунктов;
- узы крови действуют на любого, кто трижды выпил;
- Ротшрек — только от огня и солнца.

**Призраки (Wraith 20)** стоят особняком:
- вместо уровней здоровья — **Корпус** (10 у всех);
- топливо — **Пафос**, у Тени — **Ангст**;
- мораль и срывы — **Тень** (Катарсис, Испытания), а не Человечность;
- живёт в Землях Теней за **Покровом**; с живыми взаимодействует через Арканои (Воплощение, Кукловодство и т. п.), смертных защищает **Туман**.

**Подменыши (C20)** тоже особняком:
- двойная природа — смертное тело и фэйская суть; урон бывает обычный и **химерический**;
- топливо — **Гламур**, угроза — **Банальность** (Туманы, Бедлам); магия — кантрипы (Искусство + Царство + обряд);
- против вампиров, оборотней, магов и призраков — файл `Подменыши/_справочник/C20_Основная/31` («Блудные дети»).

Как вампирские Дисциплины и Дары действуют на призраков, в Wraith 20 описано лишь частично (файл `Wraith20_Основная/26_Мир_Тьмы_Смертные_и_Пробуждённые`) — остальное решение системы.

Остальное (Делириум против вампиров и магов, Становление мага, гуль из Гару или мага, магия против Дисциплин) **в книгах 20-летия разбросано или не описано**. Это решения Камня. Помечать их в своей системе как «правило системы», а не как правило книги. Ориентир:
- Делириум на вампиров не действует; на пробуждённых магов — проверить в W20 и M20 ?
- Маг после Становления теряет Аватар и Арете (лор M20) ?
- Магию против Дисциплин и Даров решать через встречный бросок или противомагию (M20, `03_Магия_и_Парадокс`).

## Экономия токенов

- Субагентов — на дешёвой модели (Sonnet или Haiku) и по одному.
- Не читать полные указатели и большие книги целиком: искать Grep по английскому названию, читать файл частями.
- Read читает не больше ~25 тыс. токенов за раз.

## Грабли Windows

- Python запускать `python -I script.py`. Скрипт писать отдельным файлом, а не через `-c` или heredoc с обратными слэшами. При `-I` переменные `PYTHON*` игнорируются, поэтому кодировку вывода задавать в самом скрипте: `sys.stdout.reconfigure(encoding="utf-8")`.
- Файлы писать в UTF-8 без BOM с переводами строк `\n`.
- В Git Bash кириллица в `grep -o` и `awk` иногда считается неверно; для подсчётов — Python.
- Временным файлам давать уникальные имена: параллельные агенты затирают одинаковые.
