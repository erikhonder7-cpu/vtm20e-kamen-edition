# Инструкция для ИИ: как использовать этот справочник

Это справочник механики Vampire: the Masquerade (и смежных линеек) на русском языке: дисциплины, магия крови, достоинства и недостатки, факты биографии, Пути и Дороги, особые правила. Он собран из ~70 книг. Механика (цены, сложности, броски, затраты, длительность) передана полностью; художественный текст пересказан или опущен. Цель — встроить эти данные в игровую систему по VtM.

## С чего начать
1. `README.md` — содержание по книгам: какой файл что содержит.
2. `Указатель_компактный.md` (~45 тыс. токенов) — **держите его в контексте как карту**: все записи указателя по строке, файлы под номерами, расшифровка номеров в начале. Нужный файл открывайте по номеру; полный указатель (~200 тыс. токенов) целиком читать незачем.
3. `Указатель.md` — полный алфавитный указатель всех сил, ритуалов, достоинств и недостатков, титулов со ссылками на файлы; одноимённые записи из разных книг сведены в одну строку. В конце — раздел «English → русский».
4. `Глоссарий_терминов.md` — английский термин → русские варианты.

## Метаданные файла
У каждого файла в начале YAML-шапка:

```yaml
book: "V20 Lore of the Clans"     # книга-источник (англ. название)
edition: "V20"                    # редакция правил
compat_v20: "native"              # совместимость с V20
source: "official_en"             # откуда взят текст
reliability: "high"               # насколько точны числа
```

| Поле | Значения |
|---|---|
| `edition` | `V20`, `V20 Dark Ages`, `V5`, `Revised` (1998–2004), `2nd Edition` (1992–1997), `1st Edition` (1991), `Dark Ages: Vampire (2002)`, `nWoD` (новый Мир Тьмы / Chronicles of Darkness), `fan`, `mixed` |
| `compat_v20` | `native` — правила V20 / V20 Dark Ages как есть; `minor` — старая редакция или фанатский материал: система та же, но числа и цены сверять с V20; `convert` — другая система (V5), нужна конверсия; `none` — другая игра (nWoD), **не смешивать с VtM** |
| `source` | `official_en` / `official_ru` — официальный текст; `fan_translation_ru` — любительский перевод; `machine_translation_ru` — машинный перевод (термины бывают сбиты); `ocr_en` — распознанный скан; `summary_ru` — конспект; `compiled` — собрано проектом; `+` — сочетание (напр. английский OCR, сверенный с русским переводом) |
| `reliability` | `high` — числа надёжны; `medium` — возможны отдельные неточности; `low` — источник сбитый, числа проверять |

## Правила приоритета
- **Основа системы — V20** (`edition: V20`, `compat_v20: native`). При расхождении одной и той же силы в разных книгах приоритет: V20 → V20 Dark Ages (для сеттинга Тёмных веков) → Revised → 2nd Edition → фанатское.
- Материалы `compat_v20: none` (папка `Прочее/` файлы 11, 12, 14, 15) — **не VtM**: другие кубы и черты (Атрибут + Навык, Нравственность). Используйте только как идеи для сюжета.
- `Fall_of_London/` — книга под **V5**; в файлах даны ориентиры пересчёта.
- Старые редакции (Revised, 2nd) часто дают те же силы с другими числами или ценами — это не ошибка, а разница редакций.
- Тёмные века имеют свою систему Дорог (вместо Человечности/Путей) и свои Добродетели; файлы `V20_Dark_Ages/`, `DA_*` относятся к ней.

## Соглашения в тексте
- Название: русское (как в RU-издании «Студии 101», где оно есть), в скобках английское: «Железная воля (Iron Will)». Английское название — самый надёжный ключ для сопоставления.
- Уровень силы: точки `•`–`••••••••••` или «ур. N». Комбинированные силы — с перечнем требований.
- Таблицы достоинств и недостатков: `| Название | Цена | Эффект |`.
- «как в V20» — правило совпадает с основной книгой V20, повторно не расписано.
- `(раб.)` — рабочий перевод проекта, не из издания.
- `?` после значения или имени — значение предположительное.

## Известные пробелы
Пропуски английских сканов там, где нашёлся полный русский перевод (wod.su), восполнены: Guide to the Sabbat 1999, Clanbook Nosferatu, Followers of Set, Tremere, Dark Ages Clanbook Salubri. Остались помеченные «(в оригинале повреждено)» места, для которых нет другого источника:
- `Revised_Основные/02c_Players_Guide_2nd_снаряжение.md` — часть таблиц оружия и транспорта.
- `DA_Low_Clans/09`, `10`, `11` — несколько названий сил и концовок описаний.
- `DA_Companion/07_Искусство_битвы.md` — привязка части значений в таблицах оружия.
- По одному-два места: `Revised_Гайды_сект/01d`, `Black_Hand/04`, `DA_High_Clans/06`, `10`, `DA_Low_Clans/06`, `DA_Tome_of_Secrets/07`, `Fall_of_London/03`, `Revised_Кланбуки/08`, `Revised_Основные/01`, `Прочее/03`, `06`, `13`, `16`.
- `DA_Clanbook_Baali/01` — Добродетели Пути Улья в издании не приведены.
- NPC-статистика городских книг и гайдов сознательно не переписывалась.

Найти все такие места: поиск по строке `в оригинале повреждено`.

## Исходники и скрипты (в соседних папках, если переданы)
- `../_текст/` — извлечённый текст всех книг (для сверки).
- `../_скрипты/index.py` — пересобрать `Указатель.md`; `meta.py` — проставить YAML-шапки; `merits.py`, `disciplines.py` — черновые CSV.
- `достоинства_и_недостатки.csv`, `дисциплины_и_пути.csv` — **черновые** автоматические выборки из сырых текстов, с мусором; надёжнее брать данные из .md.

## Рекомендуемый порядок встраивания
1. Ядро V20: `V20_Основные_правила/` (базовая механика: проверки, бой, кровь, мораль, гули — начинать с неё), затем `Дисциплины/`, `Достоинства_и_недостатки/`, `Факты_биографии/`.
2. Расширения V20: `Lore_of_the_Clans/`, `Lore_of_the_Bloodlines/`, `Rites_of_the_Blood/`, `Black_Hand/`, `Anarchs_Unbound/`, `Hunters_Hunted_II/`, `V20_Companion/`, `Dread_Names/`, `Becketts_Jyhad_Diary/`.
3. Тёмные века (если нужен сеттинг): `V20_Dark_Ages/`, `DA_Companion/`, `DA_Tome_of_Secrets/`, затем `DA_*`.
4. Revised и 2nd Edition — как дополнительные силы, линии крови и варианты; числа сверять с V20.
5. `Прочее/` — по метаданным, выборочно.
