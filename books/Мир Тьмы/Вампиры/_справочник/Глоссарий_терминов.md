# Глоссарий терминов — Vampire: the Masquerade / Requiem

**Источник:** `WtWf_Vampire Translation Guide.txt` (Vampire Translation Guide, M. McFarland, White Wolf 2010) — англоязычное руководство по **конверсии Masquerade ⇄ Requiem**, а не словарь переводов: готового списка «английский → русский» в нём нет. Поэтому глоссарий собран из трёх источников: (1) термины и соответствия самого гайда (кланы, ковенанты/секты, Дисциплины, черты и системы); (2) русские названия, принятые в проекте (справочник `_справочник\…`, русские издания Revised/V20/Dark Ages); (3) раздел «Достоинства и недостатки» выгружен автоматически из `достоинства_и_недостатки.csv` и `Указатель.md` (только названия, у которых в проекте есть русский перевод). Варианты перевода разделены «/». Пометка **(раб.)** — рабочий перевод без подтверждения русским изданием (в первую очередь термины Requiem). Полный список названий сил Дисциплин, ритуалов и путей — в `Указатель.md` (раздел «English → русский»).

## 4. Черты и системы

### Соответствия Masquerade ⇄ Requiem (по гайду)
| Masquerade | Requiem | Замечания |
|---|---|---|
| Generation (Поколение) | Blood Potency (Потенция крови, раб.) | Стартовое 13-е поколение = 1 точка Потенции; −1 поколение = +1 Потенции; Потенция растёт со временем, Поколение — только диаблери |
| Blood pool (Запас крови) | Vitae (Витэ) | |
| Humanity (Человечность) | Humanity (Человечность) | В Requiem по умолчанию 7; у смертных — Morality |
| Paths of Enlightenment (Пути Просветления) / Roads (Дороги) | — | Нет аналога; пороги грехов отличаются |
| Virtues: Conscience, Self-Control, Courage (Совесть, Самоконтроль, Смелость) | Virtue & Vice (Добродетель и Порок) | В Requiem Добродетелей нет; Воля = Resolve + Composure |
| Nature & Demeanor (Природа и Маска) | Virtue/Vice | Можно использовать вместе |
| Willpower (Сила Воли) | Willpower | M: автоуспех; R: +3 кубика |
| Backgrounds (Предыстория / Дополнения) | Merits (Достоинства) | Исключение — Generation |
| Merits & Flaws (Достоинства и недостатки) | Merits / Flaws | В R недостатки дают опыт при срабатывании |
| Attributes: Perception, Appearance, Charisma | Attributes: Resolve, Composure, Presence | Perception → Wits + Composure; Charisma ≈ Presence |
| Abilities (Способности): Talents, Skills, Knowledges | Skills: Physical, Mental, Social | |
| Specialty (Специализация) | Skill Specialties | |
| Blood Bond / Vinculum (Кровные узы / Винкулум) | Vinculum | Три глотка |
| Frenzy (Неистовство) | Frenzy | |
| Rötschreck (Рётшрек) | Fear frenzy | |
| Torpor (Торпор / Оцепенение) | Torpor | |
