## Глоссарий
- `Глоссарий_терминов.md` — английский → русский: кланы, Дисциплины, секты, черты, ~430 достоинств и недостатков. Основа — Vampire Translation Guide (это гайд конверсии Masquerade ⇄ Requiem, а не словарь), поэтому термины Requiem даны с пометкой «(раб.)» — рабочий перевод.

## Для ИИ
- `AGENTS.md` — инструкция для ИИ, встраивающего справочник в систему: метаданные файлов (редакция, совместимость с V20, надёжность), приоритеты, синонимы названий, известные пробелы.
- В начале каждого файла — YAML-шапка с метаданными; проставляется скриптом `python -I _скрипты/meta.py`.

## Указатель
- `Указатель.md` — алфавитный указатель по всем файлам справочника: силы, ритуалы, достоинства и недостатки, титулы, разделы; одноимённые записи из разных книг сведены в одну строку со ссылками. В конце — раздел «English → русский»: английское название и все русские варианты, под которыми оно записано.
- `Указатель_компактный.md` — то же самое сжато для ИИ (~45 тыс. токенов вместо ~200 тыс.): файлы под номерами, по строке на запись.
- Пересобрать оба после добавления файлов: из папки Вампиры `python -I _скрипты/index.py`.

## Черновые индексы (автоматические)
- `достоинства_и_недостатки.csv` — ~890 записей из всех книг (название, тип, стоимость, книга, страница PDF).
- `дисциплины_и_пути.csv` — ~1550 строк, черновик с мусором.
- Пересобрать: из папки ВТМ `python -I _скрипты/merits.py` и `python -I _скрипты/disciplines.py`.
