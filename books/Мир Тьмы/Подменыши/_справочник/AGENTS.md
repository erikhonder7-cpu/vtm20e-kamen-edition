# Инструкция для ИИ: как использовать этот справочник

Справочник механики Changeling: The Dreaming 20th Anniversary (C20) на русском языке:
- мир, киты, Дома, создание персонажа;
- черты, Фоны, Достоинства и Недостатки;
- кантрипы, Обряды и Высвобождение, 18 Искусств и Царства;
- Темперы, Гламур, Банальность, Туманы, Кошмар и Бедлам, Клятвы, Эпифании;
- бой и здоровье;
- Грёза, троды, фригольды и поляны, химеры, Реды и Сокровища;
- противники (Блудные дети, Дантаины и Руин, Осенние люди, Таллейны, Денизены);
- галлейны, Кинейны и Зачарованные.

Собран из 4 книг (49 файлов). Механика передана полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Цель — встроить данные в игровую систему (вместе с V20, W20, M20 и Wraith 20 — см. `../../CLAUDE.md`).

## С чего начать
1. **`Указатель_компактный.md` (~17 тыс. токенов) — держите его в контексте как карту.** Все записи указателя по строке, файлы под номерами (расшифровка — в разделе «Файлы»). Нужный файл открывайте по номеру; полный `Указатель.md` целиком читать незачем.
2. `README.md` — содержание по книгам: какой файл что содержит.
3. `Глоссарий_терминов.md` — принятые термины English → Русский.
4. Базовая механика (`C20_Основная/`):
   - `04`–`06` — создание персонажа, черты, Достоинства и Недостатки;
   - `07` — кантрипы и Высвобождение;
   - `08`–`13` — Искусства и Царства;
   - `14`–`16` — правила, Гламур и Банальность;
   - `17` — бой и здоровье.
5. `_термины_рабочие.md` — рабочий словарь, по которому писались файлы (дополнять при правках). `_прогресс.md` — журнал разбора книг.

## Метаданные файла
У каждого файла в начале YAML-шапка:

```yaml
book: "Changeling: The Dreaming 20th Anniversary Edition"   # книга-источник (англ. название)
edition: "C20"                                              # редакция
compat_c20: "native"                                        # совместимость с C20
source: "official_en"                                       # откуда взят текст
reliability: "high"                                         # насколько точны числа
```

| Поле | Значения |
|---|---|
| `edition` | `C20`; `mixed` (глоссарий) |
| `compat_c20` | `native` — правила C20 как есть; `minor` — старая редакция (сверять); `none` — другая игра |
| `source` | `official_en` — официальный английский текст; `compiled` — собрано проектом |
| `reliability` | `high` — числа надёжны; `medium` — возможны неточности; `low` — источник сбитый |

## Правила приоритета
- **Основа — основная книга C20.** Players Guide, Book of Freeholds и Kithbook: Boggans расширяют её: новые киты и Дома, тайные общества, ликийцы, Искусства Вливание и Сказ; фригольды и поляны; богганы.
- Приложения основной книги (файлы 37–42: галлейны, Кинейны, Зачарованные) — дополнительные варианты персонажей со своими правилами (Ву Тань у Хсиен, Якоря и Оболочки у Инанимае и т. п.).
- Стыковка с другими линейками — `../../CLAUDE.md`; как противники C20 видят вампиров, оборотней, магов, призраков — файл `C20_Основная/31`.

## Соглашения в тексте
- Название: «Русское (English)». Английское название — самый надёжный ключ для сопоставления.
- Кантрипы Искусств: `### • Название (English)` → обряд, система, Царства, длительность, Тип (Химерический / Вирд).
- Таблицы Достоинств и Недостатков: `| Название | Цена | Эффект |`.
- «как в …» — правило совпадает с указанным местом, повторно не расписано.
- `(раб.)` — рабочий перевод проекта; `?` — значение предположительное; «(в оригинале повреждено)» — дыра в источнике.

## Разные русские названия одного и того же
Сопоставляйте по английскому названию. Принятые формы — первые; при правке выравнивайте по ним.

| Английский | Принято / встречалось раньше |
|---|---|
| Reaving | Расхищение — кража Гламура из чужого баэлфайра (в Book of Freeholds было «Разорение») |
| Ravaging | Разорение — добыча Гламура разрушением мечты смертного; **не путать с Reaving** |
| Balefire | баэлфайр (раньше местами «балефайр») |
| Manor | Мэнор (раньше «Поместье») |
| Lost Ones | Потерянные (раньше «Заблудшие») |
| Geas | Гейс (раньше «Гис») |
| Birthrights / Frailties | Дары рода / Слабости |
| Bestowments (Зачарованные) | Пожалования (не «Дары» — слово занято Birthrights) |
| Nightmare / Imbalance | Кошмар / Дисбаланс |
| Lore / Persuasion / Socialize | Знание преданий (Lore) / Убеждение (Persuasion) / Общение (Socialize) — рабочие переводы: в таблице способностей (`C20_Основная/05`) для них не было русских названий |

Остальные пары — раздел «Одно английское название — несколько русских вариантов» в `Глоссарий_терминов.md`.

## Известные пробелы и сомнительные места
Помеченное в файлах находится поиском строк `повреждено`, `приблизительн`, `?)`. По отчётам агентов **сверить с оригиналом**.

Основная книга:
- `17`:
  - таблица токсичности — болезни и яды разделены по смыслу;
  - броня и щиты — соответствие восстановлено по порядку; у крышки мусорного бака в таблице броня 3, в примере 2;
  - вывих: в тексте Сила + Драка, в таблице Ловкость + Драка (взят текст);
  - скорость бега «20 ярдов × (3 × Ловкость)» — вероятно, опечатка оригинала.
- `18` — таблица Туманов при входе в Грёзу и столбец «срок» при выходе: столбцы разошлись, восстановлено по порядку.
- `15`–`20` — номера страниц в строке «Источник» приблизительны.
- Ожесточённое сердце (Hardened Heart) — длительности противоречивы («?»).
- Не указано число кубиков урона Клинка Белтейна.
- Описание Реда «Одержимость» (Possession) в оригинале оборвано.
- Клятва скрещённых клинков — неоднозначно «меняет Волю на Гламур».
- `38` — модификаторы сложности духовного мира у племенных фэ перемешаны («?»).
- `39` — стоимости свободных очков и опыта Хсиен и начальная Чи по Кваннон-цзинь повреждены, частично восстановлены по смыслу.
- `40` — пары противоположных Слайверов взяты из описаний (таблица перепутана).

Дополнения:
- `C20_Kithbook_Boggans/03` — повреждены заголовки Достоинств «Герой закулисья» и «Сваха от рождения» и Сокровища «Чайный сервиз».
- `C20_Kithbook_Boggans/01` — противоречие: основная книга говорит, что богган не проваливает Ремесло, а Kithbook описывает ботчи как комические травмы.
- `C20_Book_of_Freeholds` — рейтинги Сил «••••• •» и «••••• •••••» (Куриная избушка, Улуру, Пещера Чудес) искажены и приведены как есть; обещано пять Полян и четыре новых Архетипа, в тексте четыре Поляны.
- `C20_Players_Guide` — номера страниц расставлены не везде.
- `C20_Основная/30` — советы Рассказчику пересказаны очень сжато (только правила).

Полный список по всем линейкам — `../../Пробелы_и_противоречия.md`.

## Исходники и скрипты (в соседних папках, если переданы)
- `../_текст/C20/` — извлечённый текст четырёх книг (для сверки; `C20 Core.txt` — 16652 строки).
- `../_скрипты/meta.py` — проставить YAML-шапки (по словарю FOLDERS); `index.py` — пересобрать оба указателя.
- Общие скрипты в `../../_скрипты/`: `abil_fix.py` (найти английские названия способностей), `probely.py` (список пробелов), `svod.py` (сводки).

3. Противники: 31–36.
4. Расширения: `C20_Players_Guide/`, `C20_Book_of_Freeholds/`, `C20_Kithbook_Boggans/`.
5. Выборочно: 37–42 (галлейны, Кинейны, Зачарованные), 30 (советы Рассказчику).
