# Инструкция для ИИ: как использовать этот справочник

Справочник механики Wraith: The Oblivion 20th Anniversary (Wraith 20) на русском языке:
- мир и создание персонажа;
- черты, фоны, Страсти и Оковы;
- 16 Арканоев Гильдий;
- Тень (Ангст, Шипы, Катарсис, Испытания);
- системы (Плёнка, Покров, Туман, Мальстрёмы, обиталища, Сон, опыт);
- бой и оружие;
- Спектры и Тёмные Арканои, Восставшие, плазмики, реликвии и Артефакты;
- другие Тёмные Царства, «Орфей».

Собран из 3 книг (39 файлов). Механика передана полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Цель — встроить данные в игровую систему (вместе с V20, W20, M20 и C20 — см. `../../CLAUDE.md`).

## С чего начать
1. **`Указатель_компактный.md` — держите его в контексте как карту.** Все записи указателя по строке, файлы под номерами (расшифровка — в разделе «Файлы»). Нужный файл открывайте по номеру; полный `Указатель.md` целиком читать незачем.
2. `README.md` — содержание по книгам: какой файл что содержит.
3. `Глоссарий_терминов.md` — принятые термины English → Русский.
4. Базовая механика (основная книга, папка `Wraith20_Основная/`):
   - `02` — броски и создание персонажа;
   - `03` — черты и общие правила Арканоев;
   - `04`–`06` — Арканои;
   - `07` — Тень;
   - `11`–`12` — системы;
   - `13`–`15` — драма, бой, оружие.
5. `_термины_рабочие.md` — рабочий словарь, по которому писались файлы (дополнять при правках).

## Метаданные файла
У каждого файла в начале YAML-шапка:

```yaml
book: "Wraith: The Oblivion 20th Anniversary Edition"   # книга-источник (англ. название)
edition: "Wraith 20"                                    # редакция
compat_wraith20: "native"                               # совместимость с Wraith 20
source: "official_en"                                   # откуда взят текст
reliability: "high"                                     # насколько точны числа
```

| Поле | Значения |
|---|---|
| `edition` | `Wraith 20`; `mixed` (глоссарий) |
| `compat_wraith20` | `native` — правила Wraith 20 как есть; `minor` — старая редакция (сверять); `none` — другая игра |
| `source` | `official_en` — официальный английский текст; `compiled` — собрано проектом |
| `reliability` | `high` — числа надёжны; `medium` — возможны неточности; `low` — источник сбитый |

## Правила приоритета
- **Основа — основная книга Wraith 20.** Book of Oblivion расширяет её: Тени и Шипы, душековка, Спектры, Буря, Лабиринт, Тёмные Царства. Handbook — советы новичкам и проводникам-Теням.
- Файлы 29–33 (другие Тёмные Царства и их Арканои) и 34–35 («Орфей», проекторы) — дополнительные сеттинги внутри основной книги, не обязательны для хроники в Стигии.
- Стыковка с другими линейками — `../../CLAUDE.md`.

## Соглашения в тексте
- Название: «Русское (English)». Английское название — самый надёжный ключ для сопоставления.
- Уровни Арканоев: `### Название (English) •••` → описание, система, затраты, сложность. «(О)» — Общий уровень, «(П)» — уровень Гильдии (см. общие правила, файл 03).
- Таблицы достоинств и недостатков: `| Название | Цена | Эффект |`; Шипы — `| Шип | Цена | Эффект |`.
- «как в …» — правило совпадает с указанным местом, повторно не расписано.
- `(раб.)` — рабочий перевод проекта; `?` — значение предположительное; «(в оригинале повреждено)» — дыра в источнике.

## Разные русские названия одного и того же
Сопоставляйте по английскому названию. Принятые формы — первые; при правке выравнивайте по ним.

| Английский | Принято / встречалось раньше |
|---|---|
| Fog | Туман (раньше «Пелена») |
| plasmics | плазмики (раньше «плазменные звери») |
| Slumber | Сон (раньше калька «Слумбер») |
| Shadow Dice | Теневые кубики (раньше «Кости Тени») |
| Doomslayers | Губители рока («Погибельщики» — только в старом имени файла) |
| Veinous Stair | Венозная Лестница (раньше «Вениозная») |
| Infamy (Шип) | Дурная слава (раньше «Печально известный») |
| Harrowing | Испытание |
| Shades (Орфей) / Shades (каста Спектров) | Оттенки (проекторы «Орфея») / Шейды — **разные понятия** |

Остальные пары — раздел «Одно английское название — несколько русских вариантов» в `Глоссарий_терминов.md`.

## Известные пробелы и сомнительные места
Помечено в файлах: `07` — цены Ангста и Тёмных Страстей в свободных очках Тени в книгах не указаны (дано по примеру, с «?»); `23` — одна пометка «повреждено».

По отчётам агентов, разбиравших книги, **сверить с оригиналом** (в файлах могут быть не помечены):
- `11` — таблица Покрова/Тумана;
- `13` — транспорт (скорости);
- `15` — привязка колонок в таблицах оружия;
- `12` — цены опыта;
- `20`–`23` — таблица опыта Спектров, цена Искусства Шейдов (Shadecraft) 6/7;
- `24` — требования к Восставшему (Кукловодство 3 + …);
- «Mint Money» — так в книге [sic];
- `Wraith20_Book_of_Oblivion/` — цена «Порождения змей» (6 очков / 8 Ангста), таблица скрываемости душековки, Арканои Искупления.

Полный список по всем линейкам — `../../Пробелы_и_противоречия.md` (дополнить разделом «Призраки» при пересборке). Найти места самому: поиск строк `повреждено`, `приблизительн`, `?)`.

## Исходники и скрипты (в соседних папках, если переданы)
- `../_текст/W20/` — извлечённый текст трёх книг (для сверки; `Wraith20 Core.txt` — 18343 строки).
