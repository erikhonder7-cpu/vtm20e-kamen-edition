# Справочник по книгам Wraith: The Oblivion 20th Anniversary (Wraith 20)

Механика трёх книг Wraith 20 своими словами, по-русски: основная книга, The Book of Oblivion и Handbook for the Recently Deceased. Броски, сложности, затраты, длительности и таблицы — полностью; художественный текст пересказан кратко или опущен; статистика NPC не переписывалась. Названия — «Русское (English)». Источник — английские тексты.

Как пользоваться ИИ — `AGENTS.md`. Термины — `Глоссарий_терминов.md` (рабочий словарь проекта — `_термины_рабочие.md`).

Нумерация основной книги: 01–07 — мир, правила, создание, Арканои, Тень; 10–15 — советы Рассказчику, Системы, Драма и бой; 20–35 — Спектры, Восставшие, Мир Тьмы, плазмики, реликвии, другие Тёмные Царства, «Орфей». Номеров 08–09 и 16–19 нет: так распределили работу, пропусков в книге там нет.

## Указатель
- `Указатель_компактный.md` — карта для ИИ: файлы под номерами, по строке на запись.
- `Указатель.md` — полный алфавитный указатель со ссылками; в конце — «English → русский».
- Пересобрать оба и YAML-шапки: из папки линейки `python -I _скрипты/meta.py`, затем `python -I _скрипты/index.py`.
